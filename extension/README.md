# chordsで開く

U-FRET・ChordWikiの曲ページの右下に「chordsで開く」リンクを追加する、Chrome／Edge向けのManifest V3拡張機能です。表示中のコードを初出順にまとめ、曲名・出典URL・カポ・元サイトの移調を `https://chords.kani3camp.com/` のURL v1へ渡します。

ツールバーの拡張機能アイコンからも開けます。左クリックでは曲名・コード数・カポ・移調と「この曲をchordsで開く」「chordsトップを開く」を表示します。アイコンを右クリックしたメニューにも「この曲をchordsで開く」があります。ページ右下のパネルを閉じても利用できます。読み込み後に譜面を変更した場合は、左クリックのメニュー内の「曲を再確認」で更新できます。

## インストール

このリポジトリの開発環境（Node.js 24、pnpm 10）で次を実行します。配布されたビルド済みフォルダーを使う場合、ビルドは不要です。

```sh
pnpm install --frozen-lockfile
pnpm build:extension
```

1. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から `dist-extension` フォルダーを選びます。ZIPの場合は先に展開してください。
3. U-FRETまたはChordWikiの曲ページを開きます。すでに開いているページは再読み込みしてください。
4. 右下の「chordsで開く」を押すと、コード一覧を別タブで開きます。

Edgeの場合は `edge://extensions` から同様に読み込めます。ビルドし直した場合は拡張機能の更新ボタンを押し、曲ページも再読み込みしてください。導入方法の参考: [Chrome公式手順](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。ストア公開とブラウザへのインストールは行っていません。

## 対応範囲

- U-FRET: `https://ufret.jp/song.php?data=...` と `https://www.ufret.jp/song.php?data=...`。現在の `.musical-sheet .chord rt` から読み取ります。
- ChordWiki: `https://chordwiki.org/wiki/...`、`https://ja.chordwiki.org/wiki/...` と、両ホストの `wiki.cgi?t=...` の閲覧画面。`.main .chord` から読み取ります。編集・履歴ページでは動きません。
- ChordWikiの新表示 `beta.chordwiki.org`、Safari、Firefox、U-FRETの旧デザインは検証対象外です。
- コードの異名は♯・♭をASCIIの `#`・`b` に揃え、それ以外は保持します。分数コード、括弧内のテンション、N.C.を扱います。入力形式に合わない注記は除外し、件数を表示します。除外内容は件数表示にマウスを重ねて確認できます。アプリに未収録のコードも名前を渡します。
- 表示中のコードは `mode=shape` で渡します。U-FRETのカポと曲キーは内部値の符号を反転して読み取ります。`sourceShift` は曲キーの変更量であり、カポに伴う押さえ方の変化は加算しません。ChordWikiでは移調セレクターと、譜面内のコメント／キー行にある `Capo: 3` などの明示的な数値を使います。カポ表記がない場合は0です。
- カポ・移調・譜面の変更と遅延読み込みを監視してリンクを更新します。リンクを押す直前にも再取得します。
- U-FRETの半音下げ／全音下げチューニング、解釈できないカポ表記、複数の異なるカポ位置、7,168バイトを超えるURLではリンクを無効にし、理由を表示します。カポやコードの記載が曲全体に当てはまるかは原譜で確認してください。
- ×でパネルを閉じられます。再読み込みで再表示します。

## 読み取りと送信

対象サイトの曲ページにだけコンテンツスクリプトを読み込みます。コード専用要素、曲名、カポ／移調設定をDOMから読み取り、歌詞本文やページのJavaScript変数は抽出しません。サーバーへの自動アクセス、定期実行、解析ログ、ブラウザストレージの利用はありません。サービスワーカーはメニュー登録とユーザーのクリック処理に使います。リンクを押したときだけコード・曲名・出典・設定をリンク先のURLへ渡します。出典URLからは曲の識別子・表示設定だけを残します。

権限は対象ページへのコンテンツスクリプト指定と、右クリックメニュー用の `contextMenus` です。現在のタブIDを取得し、そのタブ内のコンテンツスクリプトに曲情報を問い合わせます。`tabs`、`storage`、`scripting`、全サイトの閲覧権限などは要求しません。

## 開発と検証

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm exec playwright install chromium
pnpm test:extension
```

`pnpm test:extension` は拡張機能をビルドし、実際に読み込んだChromiumで、歌詞を含まない自作のサイト構造フィクスチャを使って検証します。両サイトでの注入・抽出、遅延読み込み、カポ／移調／コード変更、URL上限、エラー時の古いリンク除去、編集画面の除外、リンクからアプリへの受け渡しを確認します。公開サイトの構造は2026-10-30に確認しました。外部サイトの変更や会員限定の画面構造によっては、セレクターの更新が必要になります。

2026-10-30の検証結果: 型検査、lint、単体81件、拡張機能のブラウザテスト5件、Webアプリと拡張機能の両ビルドが成功しました。U-FRETの公開曲ページでも拡張機能から8種類のコードのリンク生成を確認しました。ChordWikiは通常ブラウザでDOM構造を確認し、構造フィクスチャで抽出を検証しました。自動テスト用ブラウザからの公開ページ表示はアクセス確認画面で停止したため、その環境での実サイトの抽出完了は未確認です。アクセス確認画面では、拡張機能はコードの表示を待つ状態になります。

`vite.extension.config.ts` はカタログやReactを含まない `content.js`、`popup.js`、`background.js` と、メニューのHTML・CSS・manifestを `dist-extension` に出力します。Webアプリのビルド・配信とは独立しています。
