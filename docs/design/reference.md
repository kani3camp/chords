## 機能を本実装へ置き換えた箇所

- プロトタイプの模擬コピーと画面内好みを、実Clipboard API・localStorage・完全クエリURLへ置換。
- Prototype注記とexampleドメインのダミー出典を削除。
- プロトタイプ独自の `mode=form|real` をNotion正本の `shape|sound` に統一。formsはセミコロンではなくトップレベルカンマで公開仕様に統一。
- 自由入力フォームは作らず、検証済み3351候補から選択。候補が複数ある元参照の単一候補カードには変更ボタンを表示。
- 確認画面はnative dialogでキーボード移動・Escape・フォーカス復帰を実装。PC・タブレットで同じ図を利用。
